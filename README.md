# AI 八字命术系统 · Destiny

> 规则引擎负责排盘（准），大模型负责解读（讲）。传统文化与娱乐用途，不构成医疗、投资、法律等任何专业建议。

通过出生时间与出生地点（经纬度），由**确定性规则引擎**完成八字排盘，再由**大模型**把结构化结果翻译成通俗易懂的命理解读报告。

**核心理念：算法决定"准不准"，AI 只负责"讲不讲得好"。** 任何 LLM 都不能修改干支、五行、大运、流年等数值结果，只接收引擎的输出做白话翻译。

- **算法负责"准"**：排盘、五行、大运流年全部由可测试的纯函数计算，结果确定、可复现。
- **AI 负责"讲"**：大模型只接收引擎算好的结构化结果，禁止自行排盘，避免幻觉。
- **合规优先**：全程带娱乐免责声明，敏感数据加密可删。

## 功能一览

- 分步录入向导：历法（公/农历）、闰月识别、农历日期合法性校验、时辰未知选项、城市经纬度、自定义省/市/区、真太阳时校正开关与量级预览、时辰边界（子时）提示
- 确定性排盘引擎：历法换算、二十四节气、真太阳时（精确到分钟）、四柱/藏干/十神/纳音、十二长生、纳音五行、命局格局、建禄/阳刃/十神格/组合格/从格、五行柱位权重 + 月令得气系数、喜用忌神、五行强弱排序、缺失五行
- 关系判定：天干五合、天干冲、地支六合、地支六冲、地支三合（含半合）、地支三会、地支六害、地支三刑、地支破
- 神煞（带出处标注）：天乙贵人、文昌贵人、太极贵人、桃花、驿马、华盖、将星、亡神、金舆、红艳、天德贵人、月德贵人、旬空（空亡）
- 大运流年：精确到月 + 时辰的起运算法（"3 天折 1 岁、1 天折 4 月、1 时辰折 10 天"），跨年节气自动处理
- 命盘可视化：四柱表（五行配色 + 十二长生）、五行力量雷达图（强弱排序 + 缺失）、大运流年时间轴、命局格局、合冲刑害破、神煞清单（含出处）、日柱旬空、命宫
- AI 解读：性格 / 事业 / 财运 / 感情 / 健康 / 六亲 / 大运流年 七维度，流式生成，Prompt 内注入 RAG 召回的知识片段
- 命盘问答：带盘面上下文与历史的多轮对话
- 账户与档案：JWT 鉴权、多档案管理、数据一键导出、删除
- 合规：Prompt 硬约束 + 内容后处理过滤（按维度的风险词库）+ 全程免责声明；出生信息应用层加密

## 排盘引擎精度概览（v1.1.0+）

- **真太阳时校正**：按经度差 ×4 + 均时差（简化公式），可跨年；显示校正量与跨日提示。
- **起运算法**：保留"3 天折 1 岁、1 天折 4 月、1 时辰折 10 天"全精度，不再四舍五入丢失时辰信息；自动用 `lunar-javascript.getNextJie/getPrevJie` 跨年取节气。
- **旺衰判定**：月令本气 ×1.8 得令 + 柱位权重（年 0.6 / 月 1.0 / 日 1.0 / 时 0.8），阈值 56% / 44% 判定强弱。
- **喜用神**：身强取克泄耗、身弱取生扶、均衡取调候。
- **十二长生**：每个地支相对日主的"长生十二"，按阴阳干顺逆与起始支位计算。
- **格局**：建禄、阳刃、十神格（食神/伤官/正官/七杀/正印/偏印/正财/偏财/比肩/劫财）、组合格（食神制杀、伤官配印、官印相生、财官双美）、从弱/从强。
- **关系**：天干五合/天干冲、地支六合/六冲/三合（含半合）/三会/六害/三刑/破。
- **神煞**：天乙、文昌、太极、桃花、驿马、华盖/将星、亡神、金舆、红艳、天德、月德、旬空，每条标注出处（"日干查"、"月支查干"等）。
- **输出结构**：`BaziChart` 增加 `relationships`、`patterns`、`shenshaDetail`、`dayXunKong`、`mingGong`、`fiveElements.rankByScore`、`fiveElements.missingElements`；`Pillar` 增加 `twelveStage` 与 `naYinElement`，供 AI 解读与前端展示使用。

## 架构约束（重要）

1. 前端不做任何命理计算。
2. 排盘引擎为纯函数、无 I/O、可复现，是唯一的"事实来源"。
3. AI 只接收引擎结果做自然语言解读，Prompt 中明确禁止重新排盘或修改任何干支/五行数据。
4. 出生时间等敏感字段应用层加密存储，用户可导出与删除。

## 术语表

| 术语 | 含义 |
|---|---|
| 八字 / 四柱 | 年柱、月柱、日柱、时柱，每柱由一个天干与一个地支配成 |
| 天干 | 甲乙丙丁戊己庚辛壬癸，共 10 个 |
| 地支 | 子丑寅卯辰巳午未申酉戌亥，共 12 个 |
| 五行 | 木、火、土、金、水，及相生（木→火→土→金→水→木）与相克关系 |
| 日主 | 日柱的天干，代表命主本人 |
| 旺衰 | 日主得令（生于当令月令）/得地/得势/得助的强弱判定 |
| 喜用神 / 忌神 | 命局中能够调节五行平衡的五行（喜用）与应当回避的五行（忌） |
| 藏干 | 地支中暗藏的天干，每个地支最多 3 个，分主气/中气/余气 |
| 十神 | 比肩/劫财/食神/伤官/正财/偏财/正官/七杀/正印/偏印，由日干与他干支五行阴阳派生 |
| 纳音 | 六十甲子每对干支对应的"金木水火土"五行组合（如"海中金"） |
| 真太阳时 | 按本地经度 + 均时差校正后的钟表时间，反映太阳真实过中天时刻 |
| 立春分界 | 八字年柱与生肖以"立春"为分界（非阴历新年），节气月同样以"节"为界 |
| 大运 | 月柱往后（或往前）顺/逆排出的十年期运势序列 |
| 流年 | 公历某年的天干地支 |
| 神煞 | 以年支/日支/日干等查表得到的吉祥/不利标记（如天乙贵人、桃花、驿马） |
| 十二长生 | 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养，对应日干在地支的状态 |
| 合冲 | 天干五合、地支六合/六冲/三合/三会/六害/三刑/破 |
| 格局 | 月令或四柱组合形成的主格局（建禄/阳刃/十神格/食神制杀/伤官配印/从格 等） |
| 起运 | 出生到进入大运的间隔；按"3 天折 1 岁、1 天折 4 月、1 时辰折 10 天"换算 |
| RAG | 检索增强生成；本项目按盘面特征加权召回命理知识片段注入 Prompt |

## 安全与隐私

- 出生时间、经纬度等敏感信息应用层 AES-256-GCM 加密存储；密钥来自 `ENCRYPTION_KEY` 环境变量。
- 用户可一键导出 / 删除本人全部数据。
- 全程 JWT 鉴权，限流器（throttle）防滥用。
- 流式 SSE 期间不缓存任何中间数据；落库仅保存脱敏的 LLM 最终输出 + 模型版本。
