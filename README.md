# AI 八字命术系统 · Destiny

> 规则引擎负责排盘（准），大模型负责解读（讲）。传统文化与娱乐用途，不构成医疗、投资、法律等任何专业建议。

通过出生时间与出生地点（经纬度），由**确定性规则引擎**完成八字排盘，再由**大模型**把结构化结果翻译成通俗易懂的命理解读报告。

- **算法负责"准"**：排盘、五行、大运流年全部由可测试的纯函数计算，结果确定、可复现。
- **AI 负责"讲"**：大模型只接收引擎算好的结构化结果，禁止自行排盘，避免幻觉。
- **合规优先**：全程带娱乐免责声明，敏感数据加密可删。

---

## 功能一览

- 分步录入向导：历法（公/农历）、时辰未知选项、城市经纬度、真太阳时校正开关
- 确定性排盘引擎：历法换算、二十四节气、真太阳时、四柱/藏干/十神/纳音、五行旺衰、喜用忌神、大运、流年、神煞
- 命盘可视化：四柱表（五行配色）、五行力量雷达图、大运流年时间轴
- AI 解读：性格 / 事业 / 财运 / 感情 / 健康 / 六亲 / 大运流年 七维度，流式生成
- 命盘问答：带盘面上下文的对话式追问
- 账户与档案：JWT 鉴权、多档案管理、数据一键导出、删除
- 合规：Prompt 硬约束 + 内容后处理过滤 + 全程免责声明；出生信息应用层加密

## 技术栈

| 领域 | 选型 |
|---|---|
| 前端 | Next.js 14 (App Router) + React 18 + TypeScript + Tailwind + ECharts |
| 后端 | NestJS + TypeScript |
| 排盘引擎 | 独立 TS 包 `@app/bazi-engine`（纯函数，100% 可单测） |
| 数据库 | PostgreSQL + Prisma |
| 缓存/限流 | Redis |
| LLM | 可插拔适配层（OpenAI 兼容协议 + 离线 Mock） |
| 部署 | Docker + Docker Compose，pnpm workspace monorepo |

## 架构约束（重要）

1. 前端不做任何命理计算。
2. 排盘引擎为纯函数、无 I/O、可复现，是唯一的"事实来源"。
3. AI 只接收引擎结果做自然语言解读，Prompt 中明确禁止重新排盘或修改任何干支/五行数据。
4. 出生时间等敏感字段应用层加密存储，用户可导出与删除。
