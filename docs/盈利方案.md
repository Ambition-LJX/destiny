# 项目盈利方案

## 一、现状判断

产品已有盈利的基础盘：**免费排盘引擎（本地计算，成本≈0）+ 付费 AI 解读（DeepSeek）**。

这个结构天然适合「免费引流、付费升级」的商业模式。真正的成本在 AI 调用，所以盈利的关键是**把 AI 解读变成付费点，并控制单客成本**。

## 二、分阶段落地路线

### 阶段 0：先算清成本账（1-2 周，现在就能做）

已具备 `costStats` 成本看板，但它是**按单次报告**统计的。要盈利，需要补两个东西：

1. **单客成本模型**：算出「一份完整报告（全部维度）+ 问答」到底花多少钱。DeepSeek-V4-Flash 很便宜，但报告维度多、问答对话长，成本会累积。
2. **额度/计数落库**：现有 `Report` 表只存了单次报告的 token，未挂到「用户级累计」。需要加一个 `UserQuota` 或账单字段，才能做付费限制。

> 目标：**先知道每个用户每月花多少钱**，否则定价就是拍脑袋。

### 阶段 1：MVP 付费（2-4 周，核心）

不做完整会员系统，先做最简单的「免费额度 + 充值解锁」：

- **免费用户**：免费排盘 + 1 次整体概览解读（`generateOverviewStream` 正好做引流，用大白话解读勾起付费欲）
- **付费解锁**：完整报告（各维度）+ 无限问答
- **支付**：先接微信/支付宝的**扫码代收**（个人可用的收款码/聚合支付），不急着上企业资质、苹果内购
- **实现**：在 `auth.service` 加额度字段，在 `reports` 接口加额度校验拦截

### 阶段 2：做内容壁垒（持续）

命理网站的留存和付费核心是**解读质量**，不是功能。已有 RAG 知识库，这是护城河——**持续往里面灌高质量命理知识**，让 AI 解读比别人家更准、更专业、更有温度。这是最容易被低估但最值钱的一环。

### 阶段 3：增长

- **内容营销 / SEO**：八字命理是搜索流量很大的领域，做「免费排盘 + 精品文章」引流
- **分享裂变**：报告生成后生成一张「精美命盘卡片」分享，送一次免费问答额度
- **会员体系**：等有稳定付费用户后再上，包月/包年

### 阶段 4：规模化盈利项（后期）

- **人工咨询对接**：AI 解读付费用户沉淀后，提供付费的人工大师预约（抽成）
- **属牌/周边**：命盘 + 生肖/五行/风水周边电商

## 三、合规注意点

命理行业有合规风险，定位必须写成 **「传统文化 / 娱乐参考」**，避免出现「预测、改运、保证」类话术。前端已有的 `Disclaimer.tsx` 和实操性免责声明要保留，并在转化话术里强化，付费转化时也要有明确提示。

## 四、建议启动顺序

先做**阶段 0 的成本模型 + 阶段 1 的免费额度解锁**，这是能用最小工作量验证「用户愿不愿意为 AI 解读付费」的关键一步。

具体落地：加 `UserQuota`/账单字段、在报告生成时计量、让看板能按「单用户」统计成本，从而看到每个真实用户的成本，为定价提供依据。
